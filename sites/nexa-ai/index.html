    Which models does Nexa support?
    Any model with a chat-completions style API, plus self-hosted open-weight models via our runner. You can route different steps to different models and set per-run cost caps.
    
        
    How do approvals work?
    Define a rule — for example “refunds over $500” or “emails to new domains”. When an agent hits it, the run pauses and a reviewer gets a one-tap approve/reject card in Slack, Telegram or the Nexa console.
    
        
    Is my data used for training?
    No. Prompts, outputs and memory are never used to train models. Data is encrypted at rest and in transit, and Scale customers can pin storage to a region or their own VPC.
    
        
    Can I self-host?
    Yes. The runner ships as a single container. Use the hosted control plane, or run the full stack on your own infrastructure under the Scale plan.
    
        
    What counts as a run?
    One trigger to completion — however many steps and tool calls the agent takes in between. Retries of failed steps are free.
