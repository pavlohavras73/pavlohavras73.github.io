BotForge Quickstart

Follow this 3-step walkthrough to build and launch your first interactive Telegram bot in under 5 minutes without writing a single line of backend code.

1

Obtain Your BotFather Token

Open Telegram and message official @BotFather to create your new bot account:

# Send to @BotFather in Telegram:
/newbot
# Provide your display name and unique username ending in 'bot'
Alright, a new bot. How are we going to call it?
Use this token to access the HTTP API: 123456789:AA-your-bot-token-here

Copy this token and paste it directly into your BotForge Bot Settings.

2

Configure Your First Flow

Open the visual flow builder canvas in BotForge and drag your starter nodes:

⚡ Trigger Node

Listens for the `/start` command or specific keywords.

💬 Message & Buttons

Sends markdown text along with responsive inline button choices.

🔀 Condition Node

Branches user path based on previous answers or tags.

3

Dynamic Variables & State

Inject user data directly into any message block with double curly braces:

{{user.first_name}} : User's Telegram first name
{{user.username}} : Telegram handle (e.g. @alex)
{{user.language_code}} : ISO code (e.g. en, de, fr)
{{order.total_amount}} : Calculated cart price
